# GlowSculpt GitHub Structure

Upload the contents of this folder to the repository root while preserving every folder.

## Feed locations

Place the five supplied product feeds in these folders:

- data/feeds/sbla-beauty/
- data/feeds/uzari-skincare/
- data/feeds/foreo/
- data/feeds/dr-sperons/
- data/feeds/indian-skin-dista/

Accepted feed formats: CSV, TSV, XLSX, XML, JSON, or ZIP.

## Important

The `.gitkeep` placeholder files make GitHub preserve otherwise empty folders. They may be removed after real files are added to each folder.
